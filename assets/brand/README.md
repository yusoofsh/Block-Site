# Block Site — Brand assets

A refreshed visual identity for the browser extension that blocks websites by hostname and helps users stay intentional online.

## Direction
- Concept: a shield with a crossbar motif — protection and deliberate control.
- Primary: midnight #0B1220 / #17243A
- Accent: mint #55DDBB / #39B995
- States: blocked coral #FF737D; paused amber #F4C66A
- Supporting: slate #64748B, pale text #F8FAFC
- Typography: Inter (fallback: Arial, sans-serif).

## Files
- assets/icons/icon.svg — default extension icon.
- assets/icons/blocked.svg — blocked state icon.
- assets/icons/paused.svg — paused state icon.
- assets/brand/wordmark.svg — horizontal logo.
- assets/brand/social-preview.svg — 1280×640 repository/social preview artwork.

The icon SVGs remain the source files for PNG icon sizes described in assets/icons/README.md. Run bun assets/icons/render.mjs with the required Chromium binary to regenerate extension PNGs.
